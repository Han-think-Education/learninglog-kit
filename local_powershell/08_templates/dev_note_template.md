# 개인 개발 글 입력 노트

이 템플릿을 `00_inbox/dev_notes`에 원하는 영어 파일명으로 복사해 작성합니다.
공개해도 되는 내용만 남겼는지 확인한 뒤, 새 노트의 `public_policy`를
`partial-public` 또는 `public`으로 직접 바꾸면 개인 개발 초안 작성 대상이 됩니다.
기존 private/internal-only 원본이나 강사님 원본의 정책은 자동 변경하지 않습니다.
아래 안내 문장은 글 생성 전에 지우세요.

## 배경과 목표

어떤 수업 개념에서 시작했는가? 내가 HTML 등으로 표현해 보고 싶은 부분은 무엇인가?

## 강사님 원본과 내 변경

강사님 방식/제공 자료와 내가 만든 화면·코드·개인 시안을 구분해서 적습니다.
출처를 공개해도 되는지와 이미지·코드 사용 범위를 확인합니다.

## 설계와 구현

요구사항 → 화면 → 데이터 구조를 어떻게 연결했는지, 실제로 구현한 범위를 적습니다.
HTML/JS/CSS는 같은 입력 폴더에 보관해도 되지만 지금은 자동 분석/업로드되지 않습니다.
글에 설명할 동작·설계 판단을 이 노트에 적습니다.

## 실제 확인한 결과

소스 확인 / 브라우저 조작 / API·DB 연결 / 테스트 실행을 구분합니다.
실행하지 않은 것은 성공했다고 적지 않습니다.

## 미확인 사항과 다음 작업

아직 검증하지 못한 부분, 다음 수업에서 이어갈 ERD 수정, 남은 제약을 적습니다.
